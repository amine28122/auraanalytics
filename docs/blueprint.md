# **App Name**: AuraTrade

## Core Features:

- User Authentication: Secure user registration and login with language selection during signup.
- Dashboard: Personalized dashboard displaying key market data and analysis tools.
- Chart Analysis Tool: Interactive chart analysis with customizable indicators and timeframes.
- AI-Powered Trade Signals: Generative AI tool that identifies potential buying and selling points based on chart patterns and market trends.
- Market Data Integration: Real-time market data feeds for various assets (stocks, crypto, forex).

## Style Guidelines:

- Primary color: Deep Indigo (#4B0082) to convey trust and intelligence.
- Background color: Very dark gray (#121212) to provide a high-contrast, focused environment.
- Accent color: Turquoise (#40E0D0) for highlighting key data and interactive elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, 'Inter' (sans-serif) for body text. This combination is clean, modern, and easy to read.
- Sharp, minimalist icons to represent market trends and analysis tools.
- Clean, data-driven layout with intuitive navigation for easy access to features.
- Subtle transitions and animations to enhance user interaction without being distracting.
